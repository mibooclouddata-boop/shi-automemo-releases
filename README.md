# SHI 제작메모 기입 프로그램

Windows용 설치 파일과 자동 업데이트 정보를 제공하는 공식 배포 저장소입니다.

## 설치

1. [최신 릴리스](https://github.com/mibooclouddata-boop/shi-automemo-releases/releases/latest)에서 `SHI_AutoMemo_Setup_버전.exe`를 다운로드해 실행합니다.
2. 프로그램을 열고 회사명·부서·이름·제작메모용 라이선스 인증키로 인증합니다.
3. 인증키는 관리자에게 발급받으세요. Drawing Manager 키는 사용할 수 없습니다.

0.2.0 이상은 실행 시 새 버전을 안내하며, 설정의 **업데이트 확인**에서도 확인할 수 있습니다. 0.1.0 사용자는 최신 설치 파일을 한 번 직접 설치해야 합니다. 기존 설정과 작업 기록은 유지됩니다.

`latest.json`은 앱의 업데이트 확인과 설치 파일 크기·SHA-256 검증에 사용됩니다.

라이선스 인증키, 고객 개인정보, 실제 엑셀·전산 자료는 공개 이슈에 올리지 마세요.
